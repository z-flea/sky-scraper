## 🎯 参数调整指南

### 如何调整刚度（Stiffness）

**作用：** 控制建筑"回正"的速度
- **增大刚度** → 摆动更快，像硬棒
- **减小刚度** → 摆动更慢，像柔软的树枝

**建议范围：** 0.1 - 20.0
**调整步长：** ±1.0（粗调）或 ±0.1（细调）

**测试方法：**
1. 建造20层建筑
2. 故意偏移放置一层
3. 观察摆动周期（应该在2-4秒）

### 如何调整阻尼（Damping）

**作用：** 控制摆动衰减速度
- **增大阻尼** → 摆动快速停止
- **减小阻尼** → 摆动持续更久

**建议范围：** 0.05 - 5.0
**调整步长：** ±0.5（粗调）或 ±0.05（细调）

**测试方法：**
1. 建造20层建筑
2. 故意偏移放置一层
3. 计时摆动持续时间（应该在5-10秒）

### 如何调整敏感度（Sensitivity）

**作用：** 控制质心偏移对倾斜角度的影响
- **增大敏感度** → 轻微偏移就明显倾斜
- **减小敏感度** → 需要较大偏移才倾斜

**建议范围：** 0.1 - 1.0
**调整步长：** ±0.05

**测试方法：**
1. 建造50层建筑
2. 连续向一侧偏移放置5层
3. 观察倾斜角度（应该明显但不夸张）
