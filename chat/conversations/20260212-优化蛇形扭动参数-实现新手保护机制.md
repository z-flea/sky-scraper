# 优化蛇形扭动参数-实现新手保护机制

## 背景

在游戏测试中发现两个主要问题：
1. 前5层楼房仍然会发生晃动和偏移，影响新手体验
2. 蛇形扭动效果中单层楼房和整体楼房的频率不协调，视觉效果不佳

## 对话内容

### 第一轮：实现前5层新手保护

**用户需求：**
前 5 层，还是启动新手保护，整体建筑不发生晃动和偏移

**实现方案：**
在以下4个位置添加新手保护逻辑：

1. **applySwayVisuals()** - 前5层不应用任何旋转和位置偏移
2. **updateFloorOscillations()** - 前5层不产生垂直振荡
3. **updateFloorLandingRotations()** - 前5层不产生着陆旋转
4. **update()** - 前5层的蛇形扭动偏移量设为0

修改文件：`src/core/game.js`

### 第二轮：分析旋转动效问题

**用户反馈：**
楼房落下后的旋转动效持续进行，1分钟后仍然会左右滑动

**分析结果：**
发现系统中有**两种独立的旋转效果**：

1. **着陆旋转（Landing Rotation）**
   - 触发时机：楼层落地瞬间
   - 物理模型：弹簧-阻尼系统
   - 预期行为：约1.25秒后衰减到0并停止
   - 稳定机制：当角度 < 0.001弧度 且 速度 < 0.01弧度/秒时停止

2. **蛇形扭动旋转（Snake Wobble Rotation）**
   - 触发时机：持续进行，每帧都在计算
   - 物理模型：基于时间的正弦/余弦函数
   - 实际行为：**永久持续振荡**
   - 公式：`wobbleRotation = accumulatedOffset * amplitude * Math.cos(phase) * phaseDelta`

**结论：**
用户看到的"1分钟后仍然会左右滑动"是蛇形扭动旋转效果，而不是着陆旋转。

### 第三轮：分析蛇形扭动频率问题

**用户反馈：**
单层楼房扭动范围和整体楼房扭动范围似乎不同频

**数学分析：**

当前参数（修改前）：
- AMPLITUDE: 1.5
- FREQUENCY: 1.5 rad/s
- PHASE_DELTA: 0.2 rad
- MAX_ACCUMULATED_OFFSET: 8.0

频率特征：
1. **单层楼房的振荡**
   - 周期：T = 2π/1.5 ≈ 4.19秒
   - 频率：f ≈ 0.239 Hz

2. **整体楼房的波传播**
   - 波长：λ = 2π/0.2 ≈ 31.4层
   - 波速：v = 1.5/0.2 = 7.5层/秒

**问题根源：**
- 最大偏移 = 8.0 × 1.5 = 12.0单位（3倍楼层宽度，过大）
- 最大旋转 = 12.0 × 0.2 = 2.4 rad ≈ 137度（过大）
- 波长31.4层，但游戏初期只有几层楼，看不到完整波形

### 第四轮：优化蛇形扭动参数

**调整方案：**

| 参数 | 原值 | 新值 | 效果 |
|------|------|------|------|
| AMPLITUDE | 1.5 | 1.0 | 整体幅度减小33% |
| FREQUENCY | 1.5 | 1.0 | 摆动周期从4.19秒→6.28秒 |
| PHASE_DELTA | 0.2 | 0.1 | 波长从31.4层→62.8层 |
| MAX_ACCUMULATED_OFFSET | 8.0 | 3.0 | 最大偏移从12.0→3.0单位 |

**预期效果：**
- 更慢的摆动：周期6.28秒，更自然
- 更平滑的波形：波长翻倍，相邻楼层相位差更小
- 更合理的偏移：最大偏移从3倍楼层宽度降低到0.75倍
- 更温和的旋转：最大旋转角度从137度降低到17度

修改文件：`config/physics_params.js`

## 关键收获

1. **新手保护机制的全面性**
   - 需要在多个系统中同时实现保护（视觉、物理、动画）
   - 前5层作为稳固基础，提升新手体验

2. **旋转效果的双重系统**
   - 着陆旋转：短期效果，会自然衰减
   - 蛇形扭动旋转：持续效果，基于时间函数
   - 两者叠加产生最终视觉效果

3. **频率协调的重要性**
   - 单层频率 vs 整体波传播频率
   - 波长需要匹配游戏的楼层数范围
   - 幅度和旋转角度需要在合理范围内

4. **参数调优的数学基础**
   - 周期 = 2π/频率
   - 波长 = 2π/相位差
   - 最大偏移 = 累积偏移 × 幅度

### 蛇形扭动数学模型

对于第 i 层楼：

**相位**：`phase = ω·t + i·δ`
- ω = FREQUENCY = 1.0 rad/s
- δ = PHASE_DELTA = 0.1 rad
- t = time（持续增加）

**水平偏移**：`x_i(t) = A·sin(ω·t + i·δ)`
- A = accumulatedOffset × AMPLITUDE
- 最大A = 3.0 × 1.0 = 3.0单位

**旋转角度**：`θ_i(t) = A·cos(ω·t + i·δ)·δ`
- 最大θ = 3.0 × 0.1 = 0.3 rad ≈ 17度
