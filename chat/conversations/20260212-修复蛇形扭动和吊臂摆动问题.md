# 修复蛇形扭动和吊臂摆动问题

## 背景

游戏中实现了蛇形扭动效果后，出现了两个关键问题：
1. 只有最上面2层楼在左右平移滑动，下面的楼层不动，整体没有弯曲摇摆效果
2. 当楼房发生偏移时，吊臂的位置也会跟着移动，需要吊臂位置固定不变

## 目标

- [x] 分析蛇形扭动只有顶部2层在动的根本原因
- [x] 修复蛇形扭动效果，让整栋楼产生弯曲摇摆
- [x] 分析吊臂跟随楼层移动的问题
- [x] 修复吊臂摆动中心，使其固定在x=0

## 问题1：蛇形扭动效果不明显

### 问题分析

**根本原因：设计冲突**

1. **新手保护过度**：前5层完全不动，在7层楼的情况下，只有第6、7层会动
2. **蛇形扭动依赖累积偏移**：公式是 `wobbleX = accumulatedOffset × amplitude × sin(phase)`
3. **累积偏移几乎为0**：因为前5层位置相同，导致累积偏移≈0，蛇形扭动幅度≈0

**问题链：**
```
新手保护（前5层不动）→ 楼层位置差很小 → 累积偏移很小 → 蛇形扭动幅度很小 → 看不到效果
```

### 解决方案（三管齐下）

#### 1. 修改蛇形扭动公式 - 添加基础摆动

**文件**：`src/core/physics.js:60-71`

```javascript
// 基础摆动幅度（不依赖累积偏移）
const baseAmplitude = 0.3;

// 累积偏移放大系数
const amplificationFactor = 0.15;

// 总摆动幅度 = 基础幅度 + 累积偏移放大
const totalAmplitude = baseAmplitude + Math.abs(accumulatedOffset) * amplificationFactor;
```

**效果**：即使累积偏移为0，也会有0.3的基础摆动，确保视觉效果明显。

#### 2. 调整新手保护机制 - 从完全不动改为减弱效果

**文件**：`src/core/game.js:655-674`

```javascript
// 新手保护：前2层（index 0-1）减弱蛇形扭动效果（30%强度）
const protectionFactor = index < 2 ? 0.3 : 1.0;

// 应用保护系数
floor.snakeWobbleOffset = {
  x: wobbleOffset.x * protectionFactor,
  rotation: wobbleOffset.rotation * protectionFactor
};
```

**效果**：前2层不是完全不动，而是有30%的摆动强度，既保护了稳定性，又有视觉效果。

#### 3. 减少新手保护层数 - 从5层改为2层

修改了3处：
- `src/core/game.js:467` - applySwayVisuals()
- `src/core/game.js:506` - updateFloorOscillations()
- `src/core/game.js:540` - updateFloorLandingRotations()

**效果**：在7层楼的情况下，第3-7层（5层）会有完整的蛇形扭动效果。

### 预期效果

- **前2层**：轻微摆动（30%强度）
- **第3-7层**：明显的蛇形扭动，形成弯曲的波浪效果
- **整体**：整栋楼从底部到顶部呈现渐进的弯曲摇摆

## 问题2：吊臂摆动中心跟随楼层移动

### 问题分析

**当前实现逻辑**

1. **楼层位置系统**
   - **逻辑位置**（`floor.position.x`）：楼层的实际物理位置，用于碰撞判定和游戏逻辑
   - **视觉位置**（`floor.sprite.position.x`）：楼层在屏幕上的显示位置 = 逻辑位置 + 蛇形扭动偏移 + 着陆旋转偏移

2. **吊臂摆动中心**（修复前）

```javascript
// crane.js:35
this.position.x = prevFloorX + this.amplitude * Math.sin(this.angularVelocity * this.time) + this.noise;
```

吊臂的X位置 = **顶层楼房的逻辑位置** + 摆动偏移 + 噪声

3. **问题根源**

```
顶层楼房逻辑位置: x = 0.5
顶层楼房蛇形扭动偏移: +0.3
顶层楼房视觉位置: x = 0.8

吊臂摆动中心: 基于逻辑位置 0.5
吊臂实际位置: 0.5 + 摆动

结果：吊臂的摆动中心（0.5）跟着楼层的逻辑位置移动
```

### 解决方案

**用户需求**：吊臂的摆动中心应该固定在 x=0，不受楼层位置影响

#### 1. 修改吊臂更新逻辑

**文件**：`src/core/crane.js:24-40`

**修改前**：
```javascript
update(deltaTime, prevFloorX, prevFloorY) {
  // 摆动中心基于 prevFloorX
  this.position.x = prevFloorX + this.amplitude * Math.sin(this.angularVelocity * this.time) + this.noise;
  this.position.y = prevFloorY + 8;
}
```

**修改后**：
```javascript
update(deltaTime, prevFloorY) {
  // 摆动中心固定在 x=0
  this.position.x = 0 + this.amplitude * Math.sin(this.angularVelocity * this.time) + this.noise;
  this.position.y = prevFloorY + 8;
}
```

**变更说明**：
- 移除 `prevFloorX` 参数（不再需要）
- 摆动中心固定为 0
- 保持 Y 轴逻辑不变（仍然跟随楼层高度）

#### 2. 修改吊臂调用逻辑

**文件**：`src/core/game.js:696-698`

**修改前**：
```javascript
const prevFloor = this.floors[this.floors.length - 1];
this.crane.update(deltaTime, prevFloor.position.x, prevFloor.position.y);
```

**修改后**：
```javascript
const prevFloor = this.floors[this.floors.length - 1];
this.crane.update(deltaTime, prevFloor.position.y);
```

**变更说明**：
- 只传入 `prevFloor.position.y`（楼层高度）
- 不再传入 `prevFloor.position.x`（楼层水平位置）

### 预期效果

- ✅ 吊臂的摆动中心固定在 x=0
- ✅ 楼层的蛇形扭动效果正常
- ✅ 吊臂不会跟随楼层的视觉偏移或逻辑偏移
- ✅ 游戏难度合理，玩家可以预测吊臂轨迹

### 潜在影响

**问题**：如果楼层的逻辑位置偏移很大（比如连续多次Great判定），吊臂和楼层之间的水平距离会越来越大。

**影响**：这是预期行为。吊臂固定在x=0，如果楼层逻辑位置偏移到x=2，那么吊臂和楼层之间确实会有2个单位的距离。这会增加游戏难度，鼓励玩家尽量打出Perfect判定。

## 关键收获

### 技术层面

1. **设计冲突识别**：新手保护机制与蛇形扭动效果产生了冲突，需要平衡两者
2. **基础值 + 动态放大**：通过 `baseAmplitude + dynamicFactor` 的模式，确保效果即使在极端情况下也能正常工作
3. **逻辑位置 vs 视觉位置**：区分游戏逻辑和视觉表现，避免混淆导致的问题
4. **渐进式保护**：从"完全不动"改为"减弱效果"，既保护新手又保留视觉效果

### 游戏设计层面

1. **固定参考点**：吊臂作为固定参考点（x=0），让玩家有稳定的预测基准
2. **难度曲线**：通过楼层偏移增加难度，鼓励玩家追求Perfect判定
3. **视觉反馈**：蛇形扭动提供了丰富的视觉反馈，增强游戏表现力
