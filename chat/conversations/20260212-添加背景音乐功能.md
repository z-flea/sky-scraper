# 添加背景音乐功能

## 背景

用户在 `assets/audio/BGM.mp3` 添加了背景音乐文件，需要在游戏中集成背景音乐播放功能。

## 目标

- [x] 集成 AudioManager 到游戏主循环
- [x] 在游戏启动时播放背景音乐
- [x] 处理浏览器自动播放策略限制
- [x] 在游戏重启时重新播放音乐

## 对话内容

### 第一轮：用户请求添加背景音乐

**用户提示：**
我 @assets/audio/BGM.mp3 添加了背景音乐，请为游戏添加背景音乐

**AI 回复：**
1. 检查项目结构，发现已有 `AudioManager` 类
2. 查看 `game.js` 文件，确认需要集成 AudioManager
3. 在 Game 类中导入 AudioManager
4. 在构造函数中实例化 AudioManager
5. 在 `start()` 方法中播放背景音乐（音量 30%）
6. 在 `togglePause()` 方法中添加暂停/恢复音乐控制
7. 在 `restart()` 方法中重新播放背景音乐

### 第二轮：用户反馈不需要暂停功能

**用户提示：**
不需要暂停功能

**AI 回复：**
移除了 `togglePause()` 方法中的暂停/恢复背景音乐代码，恢复为原始的简单暂停逻辑。

### 第三轮：用户反馈没有听到音乐

**用户提示：**
我打开页面没有听到

**AI 回复：**
1. 识别问题：现代浏览器的自动播放策略会阻止自动播放音频
2. 解决方案：
   - 添加 `bgmStarted` 标志跟踪音乐是否已播放
   - 移除 `start()` 方法中的自动播放代码
   - 在 `releaseFloor()` 方法中，用户第一次点击时播放音乐
   - 在 `restart()` 方法中重置 `bgmStarted` 标志
3. 原理：浏览器允许在用户交互（点击）后播放音频

### 第四轮：用户添加设置面板

**系统提示：**
用户修改了 `index.html`、`game.js` 和 `audio_manager.js`，添加了设置面板功能，包括：
- 音量控制滑块
- 游戏历史记录显示
- SettingsManager 集成

## 关键收获

1. **浏览器自动播放策略**
   - 现代浏览器（Chrome、Firefox、Safari）默认阻止自动播放音频
   - 必须在用户交互（点击、按键）后才能播放音频
   - 解决方案：在用户第一次点击时播放音乐

2. **AudioManager 集成**
   - 使用已有的 AudioManager 类，避免重复造轮子
   - 在 Game 构造函数中实例化 AudioManager
   - 使用 `bgmStarted` 标志避免重复播放

3. **音量设置**
   - 背景音乐默认音量设置为 0.3（30%）
   - 避免音乐过大影响游戏体验

4. **代码组织**
   - 音频管理逻辑集中在 AudioManager 类中
   - Game 类只负责调用 AudioManager 的方法
   - 保持代码的模块化和可维护性

   - 在构造函数中添加 `this.bgmStarted = false`
   - 在 `releaseFloor()` 方法开头添加首次播放逻辑
   - 在 `restart()` 方法中重置 `bgmStarted = false`

### 关键代码片段

```javascript
// Game 构造函数
this.audioManager = new AudioManager();
this.bgmStarted = false;

// releaseFloor() 方法开头
if (!this.bgmStarted) {
  this.audioManager.playBGM('assets/audio/BGM.mp3', 0.3);
  this.bgmStarted = true;
  console.log('Background music started');
}

// restart() 方法
this.bgmStarted = false;
```
