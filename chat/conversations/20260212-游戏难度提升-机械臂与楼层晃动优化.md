## 对话概述

本次对话主要围绕提升游戏难度展开，通过多个维度的优化来增强游戏挑战性：

1. **机械臂摆动速度递增**：实现了随楼层阶段（Phase 1-5）递增的机械臂摆动速度
2. **楼层晃动幅度和频率提升**：增强了楼层的蛇形扭动效果
3. **动态不稳定度系统**：基于顶部5层对齐情况动态调整晃动幅度
4. **对准判定机制优化**：收紧判定窗口，增加不稳定度惩罚

### 2. 楼层晃动动态系统

**实现位置：**
- `config/physics_params.js` - SNAKE_WOBBLE 配置
- `src/core/game.js` - calculateInstabilityFactor()

**晃动参数：**
- AMPLITUDE: 1.5（晃动幅度系数）
- FREQUENCY: 1.5 rad/s（晃动频率）
- 不稳定度系数：1.0 - 2.0（基于顶部5层对齐情况）

**计算公式：**
```
最终晃动 = SNAKE_WOBBLE.AMPLITUDE × wobbleAmplitude × instabilityFactor
不稳定度系数 = 1.0 + min(avgOffset / 2.0, 1.0) × 1.0
```

**效果：**
- 堆得好 → 塔稳定 → 晃动小 → 容易继续
- 堆得差 → 塔不稳 → 晃动大 → 更难对准 → 正反馈循环

### 3. 对准判定机制优化

**实现位置：**
- `src/core/physics.js` - calculateOverlapByOffset()
- `src/systems/judgment.js` - judgmentRules

**判定窗口调整（方案 A1）：**
- Perfect: 5% → 4%（收紧 20%）
- Great: 20% → 16%（收紧 20%）
- Okay: 50% → 45%（收紧 10%）

**不稳定度惩罚调整（方案 B1）：**
- Great: instability +5 → +8（增加 60%）
- Okay: instability +20 → +30（增加 50%）

**关键机制：**
- Perfect 磁吸修正：自动对齐到上一层中心，instability -10
- 相对位置判定：基于视觉位置（逻辑位置 + 蛇形扭动偏移 + 着陆旋转偏移）

## 关键收获

### 技术收获
1. **渐进式难度设计**：通过多个维度（速度、幅度、判定）逐步提升难度
2. **正反馈循环**：不精准 → 不稳定 → 更难对准，形成挑战性
3. **动态参数系统**：基于游戏状态（楼层高度、对齐情况）动态调整难度
4. **平衡性设计**：保留 Perfect 磁吸修正，给玩家容错空间

### 设计原则
1. **温和递增**：避免突然的难度跳跃
2. **可预测性**：玩家可以通过技巧提升来应对难度
3. **正反馈**：不好的操作会导致更难的情况，鼓励精准操作
4. **容错机制**：Perfect 判定仍有磁吸修正，不会过于惩罚
