## 关键测试结果

### 共振效果验证
```
连续 3 次右侧落地:
- 第 1 次: 角度 1.29° (基础摆动)
- 第 2 次: 角度 3.37° (共振放大 2.6x)
- 第 3 次: 角度 5.40° (持续共振 4.2x)
```
**结论**: 共振机制正确，连续同侧落地导致摆动累积

### 刚度变化验证
```
楼层 10:  刚度 0.8   (刚硬)
楼层 50:  刚度 0.575 (中等)
楼层 100: 刚度 0.2   (柔软)
```
**结论**: 刚度线性降低，高楼层摆动更慢更柔软

### 倒塌阈值验证
```
10 层:  15° 倒塌
50 层:  11° 倒塌
100 层: 7° 倒塌
```
**结论**: 阈值随楼层降低，高楼层更容易因摆动倒塌

## 技术亮点

### 1. 共振机制设计
通过检测速度和偏移的方向一致性，实现了真实的共振效果。同侧落地放大力量，反侧落地抵消力量，符合物理直觉。

### 2. 枢轴旋转视觉
使用枢轴点旋转而非整体旋转，模拟了真实建筑的弯曲效果。顶部楼层旋转角度最大，底部楼层保持稳定。

### 3. 动态刚度系统
刚度随楼层数线性降低，使得高楼层更柔软、摆动更慢，增加了游戏的策略深度和挑战性。

### 4. 双重阻尼设计
结合加速度阻尼和速度阻尼，确保摆动既有真实感又能快速衰减，避免无限摆动。
