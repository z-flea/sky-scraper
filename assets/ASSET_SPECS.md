# Sky Scraper - 素材规范文档

本文档定义了游戏中所有视觉素材的技术规格，确保素材与代码中的几何体尺寸匹配。

**重要提示**：在制作新素材前，请务必查看本文档和对应代码中的几何体尺寸，确保宽高比匹配。

---

## 通用规范

### 文件格式
- **图片格式**：PNG（支持透明通道）
- **音频格式**：MP3（BGM）/ OGG（音效）
- **字体格式**：TTF / WOFF2

### 图片质量
- **分辨率范围**：512 - 2048 像素
- **色彩模式**：RGBA（支持透明通道）
- **压缩**：使用 PNG 优化工具压缩，保持视觉质量

### 透明度处理
- 透明区域使用完全透明（Alpha = 0）
- 避免半透明边缘（会导致渲染问题）
- 使用 `alphaTest` 过滤半透明像素

## 制作流程

### 标准流程

1. **查看代码**
   - 找到对应的几何体定义（如 `PlaneGeometry(width, height)`）
   - 记录几何体的宽高比

2. **计算素材尺寸**
   - 根据几何体宽高比确定素材宽高比
   - 选择合适的分辨率（512-2048）

3. **制作素材**
   - 按照规格制作
   - 确保透明区域完全透明
   - 避免半透明边缘

4. **测试验证**
   - 在游戏中加载测试
   - 检查是否有拉伸、压缩、闪烁等问题
   - 必要时调整纹理的 `repeat` 和 `offset`

5. **优化**
   - 使用 PNG 优化工具压缩
   - 确保文件大小合理（< 1MB）

### 常见问题

**Q: 为什么我的纹理显示不正常？**
A: 检查几何体宽高比和图片宽高比是否匹配。使用 `file` 命令查看图片尺寸。

**Q: 如何计算宽高比？**
A: 宽高比 = 宽度 / 高度。例如：1600 / 2656 ≈ 0.6

**Q: 纹理有闪烁怎么办？**
A: 使用纹理加载回调，确保加载完成后再显示。设置 `alphaTest` 和 `depthWrite: false`。

**Q: 如何裁剪纹理？**
A: 使用 `texture.repeat.set(ratio, ratio)` 和 `texture.offset.set(x, y)` 来裁剪。

// 吊线几何体
